## Older builds

Older builds remain available in [Git history](https://github.com/Jeanedb/MP-SHOOT/commits/main/). The [original pre-cleanup archive](https://github.com/Jeanedb/MP-SHOOT/tree/d31774e) contains the builds through V220; later retired builds can be recovered from subsequent commits. This cleanup removes older build files from the current directory without rewriting history, so it does not remove their stored Git history or substantially reduce a full clone's download size.
